# Tooltip — Constitution

This component follows the Norato RTL-first Vue 3 constitution: Lemon defines the reference anatomy and visual matrix; Norato semantic tokens define color and typography; Reka owns tooltip timing, positioning, focus/hover behavior, and collision handling. Essential content must remain available outside a tooltip. A Tooltip cannot contain interactive links or forms; rich presentation is still informational and dismisses naturally. All target affordances remain independently keyboard accessible, and the preview stays inert.
