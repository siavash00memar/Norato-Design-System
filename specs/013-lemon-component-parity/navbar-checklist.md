# Navbar — Definition of Done

- [ ] Lemon composition and exact visible behavior recorded; Norato's own palette preserved.
- [ ] All desktop layout/style and mobile type/style combinations are represented without distortion.
- [ ] Actual public adapter API has correct RTL/navigation semantics, nested links, current/disabled behavior and consumer slots.
- [ ] All interactive targets are at least 48px; keyboard focus is clear; submenu and dialog behaviors are usable; motion respects reduced-motion.
- [ ] App, Website and Centered align correctly; transparent/floating/bar styles remain readable and bounded.
- [ ] Mobile drawer and all mobile header variants fit 390px and a narrow 320px viewport without horizontal overflow.
- [ ] Button-style page structure: inert preview, executable playground, synchronized copyable usage and nine contract sections.
- [ ] Desktop and same-viewport mobile screenshots/measurements compared to Lemon; component's family/state matrix reviewed.
- [ ] Keyboard, focus, Escape, outside action, disabled/current links, controlled search, Back, RTL and accessibility tree verified in browser.
- [ ] `pnpm check:tokens`, `pnpm check:catalog`, Vue typecheck/build, Navbar tests and `git diff --check` pass.
- [ ] Catalog, contract, API exports, primitive map, usage, Figma rules, request checklist and error log agree; remaining work is disclosed.
- [ ] Changes committed and pushed; local `master` and remote `origin/master` match.
