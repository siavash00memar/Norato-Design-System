# Select State Gallery — Constitution

## Authority

This subfeature follows the root project Constitution and the current Select contract, the user's Lemon reference at `https://lemonui.ir/#select`, and Norato's semantic tokens.

## Invariants

- Keep the change limited to the static Select States documentation gallery; do not alter `NoratoSelect` runtime behavior, adapter API, or playground.
- Match the observed Lemon States section structure: state cards with a short state title and explanatory description. The actual control specimens belong to the Lemon Variants section.
- Preserve Norato's palette/tokens, Persian copy, RTL, Button-like page structure, and bounded layout.
- Keep state cards decorative/inert. Do not pretend they are interactive or expose duplicate controls to assistive technology.
- Audit the shared generic state-card styles and scope the Select presentation deliberately; do not add undocumented temporary overrides.

## Workflow

Follow `Constitution → Specify → Clarify → Plan → Checklist → Tasks → Analyze → Implement`; no UI/CSS change before the artifacts and analysis are recorded.
