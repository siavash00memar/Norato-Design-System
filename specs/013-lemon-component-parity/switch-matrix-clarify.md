# Switch Matrix — Clarify Gate

## Decisions

- The contract already records all Switch and Switch Field axes; the unresolved gap is their dedicated visual representation.
- Present 30 Switch combinations in five state groups (six size/value cells each) and six Switch Field combinations in three state groups (two on/off cells each).
- Use static, inert track/knob illustrations derived from the same tokens and dimensions as the live adapter; do not fabricate a runtime API.
- Keep 48px cells for clear target-context scale while retaining 32/40/48px intrinsic track widths and 20/24/28px intrinsic heights.
- Keep Norato semantic accents; use Lemon for hierarchy and grouping.

No API or behavior decision is unresolved for this bounded gallery change.
