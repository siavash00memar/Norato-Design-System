# Menu — Constitution

- Norato Menu is an action menu opened from a labeled overflow trigger; it is not the page's primary action and does not replace website navigation.
- Preserve Lemon's information hierarchy: floating panel, compact action rows, icon on the right in RTL, shortcut on the left, separators between groups, and destructive action last.
- Use Persian RTL by default, Estedad for the trigger/section title where appropriate, Vazirmatn for item copy, and semantic Norato surface, text, yellow, error, border and focus tokens.
- Use an installed and exported accessible menu primitive where it fits; do not hand-roll roving focus, dismissal, submenu semantics or portal behavior without a specific documented gap.
- Keep icons intrinsic and decorative; never stretch them to fill rows. Keep panel bounded, avoid viewport/document overflow, and retain a minimum 48px interactive target.
- Preserve keyboard opening, arrow navigation, Home/End, Escape/focus restore, submenu navigation, disabled behavior and outside dismissal.
- Keep Lemon's glass-and-neutral composition while using Norato's own yellow accent and semantic red for destructive actions.
- Follow Button page structure: bounded inert specimen, interactive Vue playground, copyable usage and full contract sections. Keep specimen inert and distinct from the executable adapter.
- Before visual edits, audit and remove/neutralize legacy menu selectors. Run the repository request checklist against the actual browser render before handoff.
