# Empty State — Constitution

- Keep this family a reusable presentation component for an intentional no-content state; feature-level fetching, error recovery, and navigation stay in the host application.
- Match design reference's visual hierarchy and 36 documented variants, while using Norato semantic colors, Estedad titles, Vazirmatn content, RTL-first layout, and current Vue 3 APIs.
- Use a concise title, useful explanation, decorative visual, and optional primary/secondary actions. Decorative visuals must not carry information required to understand the state.
- Preserve the 48px minimum target for actions; do not distort icons, illustrations, or layout across variants or breakpoints.
- Keep the catalog specimen inert and separate from a live Vue playground; actions shown in the preview must not perform product navigation.
- Do not claim family DoD complete until matched design reference/Norato render review, variants, RTL, responsive behavior, interaction/accessibility evidence, and engineering gates are recorded.
