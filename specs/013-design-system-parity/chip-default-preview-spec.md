# Chip default preview — Specify

## Goal

Make the static Chip specimen show the actual unselected default and keep its responsive frame aligned with the same-width reference.

## Acceptance

- The static sample is «طراحی», RTL, filter mode, `aria-pressed=false`, with no selected check icon.
- The neutral surface keeps its 1px `#E8E8E8` stroke; selected and focus states keep Norato yellow.
- The mobile specimen frame uses the established 328px token cap and stays centered without document overflow.
- The visual capsule remains intrinsic and is not stretched to the interaction target.
- The Button-style component page structure and public adapter API remain unchanged.
