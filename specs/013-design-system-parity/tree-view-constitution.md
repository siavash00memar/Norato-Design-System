# Tree View — Constitution

- RTL/Persian is the default; child levels advance 20px from the right. File labels receive an additional 16px visual offset to align with folder labels.
- design reference is the visual hierarchy reference. Use Norato semantic tokens and its yellow accent for hover, selection and keyboard focus; do not inherit design reference's literal colors.
- The inert preview shows the Default composition inside the Button-sized dotted frame. Guides default Off, matching design reference's selected default; a separate live playground exposes Guides On/Off.
- Keep trees to a recommended maximum of four levels. Preserve intrinsic folder/file icons and chevrons; never stretch icons or rows.
- Runtime tree rows remain at least 48px high. Keyboard access follows the tree pattern: Up/Down, Home/End, Left/Right, Enter/Space and typeahead; focus and selection are separately represented.
- The page follows Button's Preview → Vue playground → Overview → Anatomy → Variants → Sizes → States → Parts → Usage → Accessibility → Tokens structure.
