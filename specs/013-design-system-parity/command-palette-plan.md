## Risks

- A global shortcut may collide with host-app inputs; ignore editable fields/composition and let consumers disable/change the key.
- Nested Combobox popup geometry conflicts with design reference's single coherent search panel; custom listbox behavior inside the Reka Dialog preserves a single dialog surface.
- Persian search normalization must not alter emitted command values.
- At narrow viewports, bound height/width and internally scroll groups/results rather than stretching rows or the document.
