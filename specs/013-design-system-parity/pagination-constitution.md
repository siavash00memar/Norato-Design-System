# Pagination — Constitution

- RTL-first Persian UI, semantic Norato tokens, Vazirmatn body and Estedad headings.
- Match design reference anatomy and interaction while retaining Norato colors.
- Provide 48px minimum page, previous and next targets at every visual size.
- Use semantic navigation and expose the selected page with `aria-current="page"`.
- Bound displayed page buttons so very long result sets do not produce huge controls.
