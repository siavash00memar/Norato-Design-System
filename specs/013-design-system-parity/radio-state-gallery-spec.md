# Radio State Gallery — Specification

## Need

Radio Button's States section currently shows a generic pill with marks, unlike design reference's five title/description cards. This artwork does not represent a radio and duplicates visual controls that belong in Variants.

## Acceptance contract

1. All five Radio Button states and all three Radio Field states remain represented.
2. Cards show state title, family, concise Persian explanation, and a Norato semantic accent; no pill/control artwork.
3. Cards remain static, inert documentation; interactive Radio examples remain in Preview and Vue playground.
4. Desktop and mobile layouts are bounded, responsive, RTL, and do not stretch content vertically.
5. Other families, including Button and Select, keep their current gallery rendering.
6. Browser comparison against design reference at equal viewport, behavior regression, project gates, and request-validation evidence are recorded.

## Out of scope

Radio adapter API, live playground, standalone screen-reader certification, and other component families.
