# Playground Field Styling — Plan

## Required sequence

1. Audit all native text/number fields and existing selectors in component playgrounds.
2. Add one shared token-based field class and apply it to each in-scope control.
3. Remove or narrow superseded field selectors so controls do not receive stacked styling.
4. Review rendered fields in representative pages and confirm field dimensions, typography, stroke, RTL/LTR, keyboard focus and target height.
5. Run token validation, Vue typecheck, production build, diff check and request-validation checklist; update the DoD evidence without closing Input prematurely.
