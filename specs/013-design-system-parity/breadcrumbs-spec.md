# Breadcrumbs — Specify

A responsive Vue breadcrumb adapter and Button-structured component page. It accepts an ordered trail, renders semantic navigation/list/link/current page, supports Plain/Glass, Small/Medium/Large, Chevron/Slash separators and optional middle collapse.
