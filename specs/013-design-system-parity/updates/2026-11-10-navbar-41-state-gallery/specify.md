# Specify — Navbar 41-state visual gallery

## Scope

Render the six variant families from `docs/component-contracts/navbar.md` inside the Navbar Variants section: desktop Navbar (9), mobile header (8), Nav Link (20), Brand (2), Mega Menu (1), Mobile Menu (1), totaling 41.

## Acceptance

- Exactly 41 separately labeled specimens render in six labeled groups and match the documented axes.
- State visuals distinguish default, hover, active, disabled, and focus; style and size variants remain discernible.
- All specimens are inert and hidden from assistive technology; the live Navbar Playground remains the source for interaction and 48px targets.
- Gallery content is RTL-first, bounded, uses Norato tokens, and preserves intrinsic icon/brand geometry.
- Existing Navbar adapter and runtime behavior do not change.
