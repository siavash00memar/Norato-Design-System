# Range mobile gallery — Specification

## Scope

At widths up to 599px, display the inert Range state specimens in two equal columns. Keep the long contract explanation below the seven real state cards rather than presenting it as a fake eighth slider state. Desktop gallery layout, state drawings, live adapter, and playground behavior remain unchanged.

## Acceptance

- RTL order is preserved; state samples retain their 48×48px target, 96×6px rail, and 20×20px visible thumb.
- At 390px and 320px viewport widths, the page has no horizontal overflow and each specimen remains legible and centered.
- Mobile state gallery uses the compact two-column reference rhythm; semantic yellow and neutral state colors remain.
- Explanatory contract text remains present but is not rendered as a control or state card.
