# Range state gallery — Acceptance specification

## Request

Replace the generic blue pill/dot currently shown for Range states with a recognizable, compact slider sample that uses Norato's yellow palette.

## Acceptance

- Dedicated RTL rail, yellow fill, centered white visual thumb, and 48px target.
- Default, Hover, Pressed, Disabled and Focus are visually differentiated using semantic Norato tokens; Disabled is muted and Focus has the established yellow focus treatment.
- No blue active dot/line, clipping, vertical stretch, or page overflow.
- Change the inert States gallery only; keep the live adapter behavior and API unchanged.
