# Specification — Command Palette desktop panel parity

## Problem

At a 1904×950 browser viewport, the static local panel measures 448×240px while the recorded matched reference panel measures 452×244px.

## Acceptance

- The inert panel measures 452×244px at 1904×950.
- Its rows and icons retain their intrinsic dimensions; no content is vertically stretched.
- Mobile frame/panel dimensions remain as recorded in the mobile parity checklist; the live dialog remains unchanged.
