# Specification — File Upload sample action

## Problem

The action that adds a sample queue item has no design-system class and renders with browser-default button chrome.

## Acceptance contract

- The action uses the shared secondary Button style, including capsule shape, Norato stroke treatment, and minimum 48px target.
- Persian label, RTL placement, queue-limit disabled behavior, and sample-item behavior stay unchanged.
- No component API or network behavior changes.
