# Specify — Input state gallery parity

## Evidence

At a matched 1536×703 browser viewport, the reference Input States section contains ten title/description cards arranged in four columns. Norato instead places 41 family-specific field samples in its primary States section. The eight adapters still need their documented state coverage.

## Acceptance

- The primary Input States section displays exactly ten compact descriptive state cards: Default, Hover, Active, Error, Disabled, Loading, Success, Read-only, Filled and Typing.
- On wide desktop, the cards use four equal columns; on mobile they use two columns without horizontal overflow.
- Each card uses Norato semantic colors, Persian descriptions and RTL text; Error and Success remain distinguishable with semantic status colors.
- The 41 adapter-specific examples remain available in a secondary section after the canonical nine sections.
- Gallery content is inert and excluded from the accessibility tree; live adapters remain the source of behavior.
- No public API or runtime behavior changes.
