# Analyze — Banner mobile tone matrix

The source has separate `is-mobile` and narrow-screen desktop composition rules. The playground exposes six tones and both layouts through controlled selectors. Browser verification exercised all six Mobile tones in exact 390px and 320px same-origin frames. Every rendered Banner was RTL; document client/scroll widths matched (375/375 at 390px, 305/305 at 320px), the Banner remained 343×105px / 273×105px, and action/close targets remained 68×48px / 48×48px. Danger exposed `role=alert`; the other five tones exposed `role=status`. No overflow or stretch defect was reproduced, so no CSS edit was appropriate. The mobile composition has not yet been compared against the reference at a matched viewport, and an independent screen-reader review remains open.
