# Constitution — Chat sample retention

- Keep the Chat adapter API and page structure unchanged.
- Preserve RTL as the default and keep all interactive controls tokenized.
- Sample visibility controls only fixture messages; it must not discard or hide messages created by the user in the playground.
- The initial playground can still show a genuinely empty conversation when fixtures are hidden and no user messages exist.
- Do not claim native file chooser behavior from source inspection alone.
