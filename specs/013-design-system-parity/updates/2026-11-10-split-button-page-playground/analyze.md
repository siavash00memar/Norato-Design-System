# Analyze — Split Button detail page playground

The `SplitButtonPlayground` component is imported and has a live API preview, controls, feedback, and generated snippet. In `App.vue`, the generic implementation section renders whenever `implementationSnippet` is truthy. Split Button has an adapter and usage key, so that condition is truthy and the sibling `v-else-if="selectedItem.name === 'Split Button'"` is unreachable. A live browser DOM check of `#component-split-button` found the page title and source snippet, but no `.button-playground` and no inputs. The fix is to add Split Button to the internal implementation playground branch, where all other component playgrounds are selected, then delete the dead sibling section. This satisfies the user's page-structure requirement without changing the adapter or inventing UI.
