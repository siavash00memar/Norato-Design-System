# Specify — staged component DoD

## Goal

Make an early baseline handoff possible across all 48 catalog families, then continue until every family passes the existing strict DoD.

## Acceptance

1. Define separate Baseline and Final DoD gates.
2. Baseline requires the common Button-like page structure; representative desktop and mobile visual review; no major stretching, clipping, or overflow; RTL and semantic palette; one primary interaction/keyboard path for interactive families (or documented N/A); and current token/catalog/type/build/diff gates.
3. Final DoD retains exhaustive family-specific variant/state review, full accessibility and responsive checks, independent screen-reader review where required, and complete evidence updates.
4. Track each of the 48 families independently and state whether evidence is complete, partial, or missing.
5. A Baseline pass is not a Final DoD pass.
