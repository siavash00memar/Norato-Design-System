# Constitution — staged component DoD

- First deliver a small, useful baseline across all 48 component families.
- Preserve the existing strict DoD as the final quality bar; the baseline must never be represented as final completion.
- Keep RTL, semantic Norato tokens, Vue 3, and the 48px interactive target mandatory in both stages.
- Record evidence and gaps per family; do not infer a pass from implementation maturity or a successful build alone.
