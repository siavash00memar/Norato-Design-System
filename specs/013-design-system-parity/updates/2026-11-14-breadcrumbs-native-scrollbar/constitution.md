# Constitution — Breadcrumbs narrow-path scrollbar

- Preserve Norato's RTL-first behavior, current item, disclosure, separator direction, and existing 48px interactive targets.
- Keep narrow paths horizontally scrollable so long labels are not clipped or compressed.
- Use existing semantic rules; add no page-local color, size, or spacing values.
- Scope any scrollbar appearance change only to the Breadcrumbs list.
- Keep the change out of project copy that names the visual reference.
