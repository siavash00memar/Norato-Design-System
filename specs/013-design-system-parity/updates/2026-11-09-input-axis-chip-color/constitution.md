# Constitution — Input variant-axis chips

- Apply the latest approved Norato accent rule: yellow is the action/focus accent; blue remains for informational links and meaning.
- Neutral variant labels are not active controls and must not imply selection or interaction.
- Preserve the current Input matrix layout, RTL flow, density, and component-specific visual samples.
- Scope the visual correction to Input unless evidence shows the same defect in another component and it is separately reviewed.
- Inspect the live browser render and run the required technical gates before delivery.
