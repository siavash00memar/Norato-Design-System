# Clarify — Avatar native-form playground

- The form is a local documentation/testing context only; it does not submit, upload, or transmit selected files.
- The shared Required and Disabled controls apply to both the Dropzone and Avatar examples.
- Fixed example field names are `attachments` and `avatar`; these are illustrative form keys, not global component defaults.
- No visible submit button is added. Existing demo actions remain `type="button"`.
