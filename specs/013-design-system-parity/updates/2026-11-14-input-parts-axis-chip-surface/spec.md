# Specification — Input Parts axis chip surface

## Goal

Remove the informational blue tint from descriptive variant labels in the Input Parts section.

## Acceptance

- In the current local Input page, descriptive `size`, `state`, `type`, and similar value chips in Parts use the neutral Norato surface, text, and border tokens.
- The separate Input Variants gallery keeps its existing neutral treatment; active field samples retain Norato yellow and semantic error/success colors.
- Other components' `.variant-axis` styling does not change.
- The reference Parts section's unboxed metadata hierarchy is considered; preserve the project-approved neutral-chip contract for this scoped correction.
- RTL wrapping and page width remain intact; Input's larger state matrix and independent screen-reader gaps remain open.
