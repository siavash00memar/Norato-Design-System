# Charts preview update — Constitution

- Preserve the Charts Vue APIs, six plot types, data order, semantic summaries/tables, keyboard actions, and RTL/LTR rules.
- Keep Norato's approved yellow-first series palette and token-driven surfaces; reference colors do not replace brand colors.
- Change only the inert default sample frame/card composition and its sizing where matched evidence shows a visual mismatch.
- Keep SVG marks proportional. At narrow widths, fit the inert sample plot rather than exposing an unnecessary internal scrollbar; retain scrolling behavior in live charts when needed.
- Validate the exact desktop, 390px and 320px renders and leave independent screen-reader review explicitly open.
