# Constitution — Modal hover visual matrix

- Preserve the established Norato yellow accent, RTL ordering, shared Button-style documentation page and semantic tokens.
- Hover feedback must remain distinct from keyboard focus; focus uses the approved 2px yellow ring.
- Validate the live Modal controls and nested fields in rendered Chromium; do not infer hover appearance from source or accessibility-tree output alone.
- Keep independent screen-reader validation as a separate open DoD item.
