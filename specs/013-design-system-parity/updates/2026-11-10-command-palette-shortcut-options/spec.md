# Specification — Command Palette shortcut options

## Acceptance

- Meta+K opens the palette when the default `k` shortcut is active.
- Setting the shortcut to `j` makes Ctrl+J open, while Ctrl+K no longer opens.
- Setting `shortcut` to `false` makes both Ctrl+K and Meta+K inert; the visible trigger remains usable.
- Restore the documented playground example after temporary option probes.
