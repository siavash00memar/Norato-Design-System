# Specify — Generic component marker colors

## Problem
Shared contract galleries still use informational blue for generic anatomy, variant, sizing, state and part markers. These decorations are not links or information statuses and make blue read as a component accent.

## Acceptance contract
- Generic anatomy/part/size/state marks use neutral Norato surfaces, text and borders.
- Active or selected generic samples use Norato yellow/warning-container tokens.
- Loading samples use Norato yellow as the component accent.
- Generic selected-option and data marks do not use informational blue.
- Preserve genuine link and information/status colors and do not change component adapter behavior, sizing or RTL layout.
