# Specification — Input axis-chip cascade

## Goal

Make every descriptive axis chip in the Input family matrix render with the documented neutral surface.

## Acceptance

- Input size, state and label-placement axis values use the neutral subtle surface and neutral Stroke.
- No informational blue remains on these non-interactive chips.
- Other component families retain their existing semantic axis styling.
- Browser render confirms the Input matrix, and repository validation passes; Input DoD remains open for broader outstanding evidence.
