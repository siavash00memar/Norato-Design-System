# Implementation — OTP visual capsule and target

Implemented a 36px visual capsule inside 48/52/56/60px shell targets. The native inputs remain transparent and fill their shells; the shell owns the one visible Stroke. Removed legacy square-cell declarations and higher-specificity app rules that drew a second outline. Static family/state OTP specimens use matching 36px capsules. Updated the Input contract and shared component rules.

Live Chrome evidence: the default six-cell Input row shows neutral capsule strokes; error shows red strokes; focusing a cell changes only that capsule to Norato yellow; Error+Disabled exposes disabled native fields and renders muted neutral cells. The live playground emitted exactly 4, 5 and 6 fields as selected. Sequential `123456` entry filled six cells and advanced focus; pasting `987654` into the first cell populated all six in order and advanced to the end. Backspace cleared the current cell and a second Backspace on the empty cell moved focus to the previous cell. ArrowLeft moved focus one cell toward the preceding index. Reload restored the default 6-cell, medium, enabled, empty playground.

`pnpm check:tokens`, `pnpm check:catalog`, `pnpm --dir apps/vue typecheck`, `pnpm --dir apps/vue build` and `git diff --check` passed. Exact 390px/320px measurements, all four computed capsule/target sizes, hover/success/loading/readonly states and independent screen-reader output remain unverified. Browser screenshots were captured at the available narrow local viewport; this is not claimed as the required exact mobile matrix.
