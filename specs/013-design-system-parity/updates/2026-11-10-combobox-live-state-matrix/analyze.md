# Analyze — Combobox live state matrix

- Acceptance is falsified by any missing/duplicate cell, incorrect value/state, incorrect color priority, capsule stretch, target below contract, broken RTL, overflow, or stale active-descendant reference.
- Do not simulate incompatible states as if they were valid; Disabled cannot be meaningfully typed into, while Filled means a committed selected value and Typing means a non-empty query.
- Do not count gallery screenshots as evidence of the live adapter.
- DOM geometry and computed style verify rendering; they do not prove independent assistive-technology behavior. Per-cell screenshot files were not saved, so this is a measured browser state matrix rather than a screenshot archive.
- Keep existing 16-combination geometry evidence distinct from a new state-by-state pass.
