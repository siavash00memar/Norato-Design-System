# Specification — Select axis chips

## Goal

Remove the pale-blue surface from descriptive Select variant-axis labels while preserving real component-state colors.

## Acceptance

- Select Type/Display/Size/State axis chips use the neutral subtle surface, secondary text and neutral border.
- Default, filled, error, selected and focus specimens retain their own semantic colors.
- The rule is scoped to Select Variants and does not affect other families.
- Mobile browser capture confirms the rendered result; project gates pass.
