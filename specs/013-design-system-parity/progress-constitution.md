# Progress — Constitution

design reference is the source for the visual structure and variant matrix; Norato owns its palette and semantic tokens. Progress applies only when total work is measurable. Linear fill starts at logical inline-start (right in RTL); circular progress begins at 12 o'clock. It is status, not an interactive control, so no focus target or focus ring is introduced. Keep the track, fill and percentage label proportional and never stretch circular geometry.
