# Command Palette — Constitution

- RTL/Persian is the default. Search text remains RTL; keyboard shortcut labels are explicitly LTR.
- design reference is the visual hierarchy reference. Norato uses its own yellow accent, semantic status colors, glass surfaces and documented tokens.
- Use Estedad for titles and Vazirmatn for body/search content. Keep the palette bounded, compact and non-stretched.
- Interactive rows preserve at least 48px targets; the inert specimen may use design reference's compact row rhythm.
- The dialog must have an accessible name, labelled search input, keyboard-operable results, disabled semantics, visible focus and focus restoration.
- The documentation page follows Button's Preview → Vue playground → Overview → Anatomy → Variants → Sizes → States → Parts → Usage → Accessibility → Tokens structure.
- Do not make palette search the only way to access commands. Do not exceed eight results in one group.
