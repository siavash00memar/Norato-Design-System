# Research: Norato Date Picker

- design reference live reference (`design reference) documents seven picker modes and nine contract sections; its rendered sample is a compact Jalali calendar in a dotted glass frame.
- Reka UI 2.11.0 exports Calendar, RangeCalendar, DatePicker, and DateRangePicker primitives. The calendar primitives include managed keyboard navigation and RTL support; Date Picker includes focus management, localization, and date-time support. Reka documents date components as Alpha, so browser verification is required before maturity is upgraded.
- `@internationalized/date` 3.12.4 provides `PersianCalendar`, `CalendarDate`, and calendar arithmetic; package metadata identifies Apache-2.0. Its source uses an arithmetic 33-year leap-year cycle and documents full Persian years through 9377. Norato's Year/Wheel UI intentionally exposes a rolling 121-year window (current year −100 through +20), so its UI range is narrower than the dependency's supported calendar range. Gregorian 2026-10-23 converted to Persian 1405-08-01 in the local runtime.
- Calendar scope limitation: this dependency implements an arithmetic Persian calendar algorithm derived from ICU; it is not a holiday authority. Do not claim official holiday completeness or astronomical-year-boundary equivalence without a separately validated Iranian calendar source.
- `Intl.DateTimeFormat('fa-IR-u-ca-persian')` on the same runtime displayed Persian date fields and `arabext` numerals. It is suitable for localized display, while `@internationalized/date` provides typed calendar arithmetic.
- No authoritative Iran holiday dataset or holiday API is present in the repository. The adapter accepts holiday Jalali dates from its consumer and marks Friday intrinsically.
- The closed field follows the existing Norato/Figma field contract; the open panel follows design reference's composition with semantic Norato tokens.
- The old draft's single-date decision is historical and superseded by the latest active user goal to bring all remaining components to design reference parity. Product behavior remains Vue 3 only under the project constitution.
