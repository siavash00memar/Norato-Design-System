# Quickstart

Use the controlled Vue 3 adapter with a Jalali string for `single`, a `{ start, end }` object for `range` and `range-presets`, `{ date, time }` for `date-time`, and Jalali month/year strings for `month` and `year`. Set `type="wheel"` for the mobile wheel mode. Pass public holiday Jalali strings through `holidays`; Fridays are styled automatically. Review keyboard semantics, RTL, errors, responsive layout, and 48px targets, then run the project validation gates.
