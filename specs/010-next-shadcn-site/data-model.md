# Data Model

## DocumentationDestination

- `id`: home, components, patterns, structures, agents, about
- `title`: Persian navigation label
- `content`: rendered documentation content

## ComponentExample

- `name`: stable component name
- `primitive`: shadcn source primitive or documented custom component
- `variants`: visual and behavioral variants
- `states`: default, focus, disabled, loading, invalid where applicable
- `contract`: link to shared Norato contract
- `frameworks`: Vue and Next.js availability
