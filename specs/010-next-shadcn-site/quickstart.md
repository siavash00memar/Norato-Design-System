# Quickstart

1. From the repository root, install workspace dependencies with pnpm.
2. Run the Next docs app from `apps/docs` using its documented dev script.
3. Open the local Next URL and visit all six destinations.
4. On Components, verify keyboard focus, labels, select interaction, textarea counter, choice controls, and responsive layout at 360px.
5. Run `pnpm check:tokens` and TypeScript validation before handoff.

The `site/` directory is a fallback preview only and is not the acceptance target for this feature.
