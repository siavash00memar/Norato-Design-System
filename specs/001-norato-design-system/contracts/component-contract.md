# Norato Component Contract

Every component specification MUST contain:

- Purpose and semantic category.
- Figma source node and Material component rationale.
- Anatomy and composition boundaries.
- Public properties, slots/children, and events.
- Variants and their intended hierarchy.
- Default, hover where applicable, pressed, focus, selected, disabled, loading, error, empty, and
  success states where relevant.
- Persian RTL behavior, label wrapping, text scaling, and localization expansion.
- Keyboard operation, focus order, accessible name, role, state, and target size.
- Responsive behavior for Compact through Extra Large widths.
- shadcn primitive evaluation and custom-build justification if needed.
- Vue, Next.js, HTML/CSS, and Tailwind usage contract.
- Verification cases and known limitations.
