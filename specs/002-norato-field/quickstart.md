# Quickstart: Norato Field

1. Load the token and core CSS packages.
2. Render the canonical HTML Field with Persian label, placeholder, helper text, error text, focus, disabled, loading, and filled states.
3. Render equivalent Vue and Next adapters with the same contract.
4. Verify RTL alignment, keyboard focus, label/message associations, minimum target size, and no layout shift.
5. Run token validation and TypeScript compilation from the repository root.

Expected result: all three adapters expose the same single-line Field behavior and use only Norato semantic tokens.
