# Input Presentation Constitution

- Preserve Norato's RTL-first direction, Lemon's compact field presentation, and Norato's semantic colors and tokens.
- Use Estedad Bold for field titles and Vazirmatn Light 12px for Persian placeholders.
- Keep the visible single-line capsule at 36px while retaining at least a 48px interaction target.
- Keep generic helper copy out of default specimens; the public helper-text API and meaningful state messages remain supported.
- Preserve the multiline height of Textarea and LTR entry direction for phone and amount values.
