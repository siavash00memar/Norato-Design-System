# Package Field Capsule Constitution

- Public NoratoField consumers must receive the same approved visual contract as the documentation playground.
- Keep the 48px interaction target and render a 36px capsule surface inside it.
- Use semantic Norato tokens; resting stroke is neutral, hover/focus is yellow, invalid is error red, and disabled keeps the neutral stroke.
- Preserve existing Vue API, RTL placeholder behavior, labels, and state semantics.
- Remove the app-only visual shim after the package stylesheet becomes authoritative.
