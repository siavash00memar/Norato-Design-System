# Banner — قرارداد کامپوننت نوراتو

**حوزه:** Feedback & Status  
**وضعیت نوراتو:** Proposed  

## Preview

نمونهٔ بصری و غیرفعال این خانواده در ابتدای صفحهٔ محلی نشان داده می‌شود؛ برچسب بالای صفحه بلوغ Norato را مشخص می‌کند.

## Overview

قرارداد طراحی Norato: پیام تمام‌عرض بالای صفحه برای اطلاعیه‌های مهم، با نسخه‌ی دسکتاپ و موبایل.

## Anatomy

- **Icon** — آیکن سمت راست
- **Message** — عنوان و توضیح
- **Action** — دکمه‌ی Secondary کوچیک
- **Close** — بستن سمت چپ

## Variants

- **Banner (12 variant):** Tone: Info، Success، Warning، Danger، Neutral، Inverse؛ Layout: Desktop، Mobile

## Sizes

- در قرارداد فعلی Norato محور اندازه برای این خانواده مشخص نشده است.

## States

- در قرارداد فعلی Norato حالت‌های مجزا برای این خانواده مشخص نشده است.

## Parts

- **Banner — 12 variant:** بنر در ۶ رنگ. ابعاد/حالت‌ها: Tone: Info، Success، Warning، Danger، Neutral، Inverse؛ Layout: Desktop، Mobile

## Usage

### راهنمای کاربرد Norato

- فقط برای پیام‌هایی که کل سایت یا اپ رو تحت تأثیر قرار میدن ازش استفاده کن.
- امکان بستن رو بذار.

### محدودیت‌های کاربرد

- بیشتر از یه Banner همزمان نذار.
- برای پیام‌های مربوط به یه فرم خاص Banner نذار؛ Alert درسته.

### جهت RTL

آیکن راست، متن وسط، اکشن و بستن سمت چپ.

## Accessibility

محتوای Banner باید قبل از ناوبری اصلی خونده بشه.

### قاعدهٔ عمومی Focus در Norato

برای اجزای تعاملی، حالت Focus با حلقهٔ ۲ پیکسلی بیرون کنترل تعریف شده است.

## Tokens

**توکن‌های semantic Norato:** `--norato-color-surface-default`، `--norato-color-text-primary`، `--norato-color-brand-blue`، `--norato-color-focus-contrast`، `--norato-color-focus-ring` و توکن‌های فاصله و شعاع تعریف‌شده برای همان کامپوننت.
