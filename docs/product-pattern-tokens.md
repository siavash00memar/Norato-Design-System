# توکن‌های الگوهای واقعی محصول

این توکن‌ها از نمونهٔ مسیر شغلی Figma استخراج شده‌اند و حالا بخشی از قرارداد رسمی نوراتو هستند.

| نقش | مقدار | کاربرد |
|---|---:|---|
| Mobile frame | 360px | قاب مرجع موبایل |
| Compact gutter | 24px | فاصلهٔ محتوای اصلی از لبه، مطابق reference واقعی Figma |
| Mobile content | 312px | عرض محتوای داخل قاب ۳۶۰ |
| Visual control | 36px | ارتفاع بصری Button/Field/Action |
| Interaction target | 48px | حداقل hit area دسترسی‌پذیر |
| Label-control gap | 6px | فاصلهٔ label و کنترل |
| Field group gap | 8px | فاصلهٔ title و گروه فیلد |
| Message padding | 12px | padding کارت پیام |
| Progress height | 48px | ارتفاع progress بالای flow |

قاعدهٔ مهم: ارتفاع بصری ۳۶ پیکسل نباید hit area دسترسی‌پذیر ۴۸ پیکسل را حذف کند؛ wrapper یا padding تعاملی باید این فاصله را جبران کند.
