# Norato Design System

This implementation starts from the approved Spec-Driven artifacts in
`specs/001-norato-design-system/`.

- Material Design 3 is authoritative for UI, UX, accessibility, interaction, and responsive behavior.
- Figma section `8772:1368` is visual inspiration.
- CSS custom properties are canonical; Tailwind is an adapter.
- Version 1 is RTL-first and Light Mode only.
- Vazirmatn is body text; Estedad is headings and titles; any former Lalezar display role uses Estedad Black (weight 900).
