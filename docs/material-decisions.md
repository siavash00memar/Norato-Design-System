# Material Decisions

- Button: choose by action emphasis; primary filled, secondary outlined or tonal.
- Field: persistent label, recoverable validation, visible focus, RTL semantics.
- Checkbox: independent selection; Radio: mutually exclusive selection.
- Search: semantic input, not generic decoration.
- Date Picker: keyboard and RTL calendar behavior require explicit adapter review.
- Dialog: only for blocking decisions; Snackbar: brief non-blocking feedback.
- Upload: drag interaction must have a keyboard/button alternative.
