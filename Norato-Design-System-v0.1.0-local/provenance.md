# منشأ و حدود اعتبار نسخهٔ ۰٫۱٫۰

تاریخ ثبت: ۲۶ اکتبر ۲۰۲۶. دستور صریح کاربر: **مبنای استخراج، لندینگی باشد که بعد از دریافت ZIP با هم اصلاح شده است؛ نه نسخهٔ اولیهٔ داخل ZIP.**

## مرجع دقیق

مسیر مرجع در زمان تهیه:

```text
C:/projects/NoratoLanding/extracted/Norato-Website-main/site/
```

پوشهٔ `site/` کنار این بسته، نسخهٔ جاریِ اصلاح‌شده است؛ نام `extracted` به‌تنهایی به معنی دست‌نخورده‌بودن محتوا نیست. فایل‌های HTML فعلی و `typography.css` تا ۲۵ اکتبر تغییر کرده‌اند. برای تطبیق دقیق به [source-manifest.json](evidence/source-manifest.json) شامل SHA-256 و اندازهٔ ۱۶ فایل مراجعه کنید؛ زمان فایل به‌تنهایی ملاک نسخه نیست.

فایل ZIP اولیه خوانده/استخراج مجدد نشده و مبنای هیچ مقدار یا تصویر این بسته نبوده است. فایل‌های `audits/`، نسخه‌های پشتیبان، خروجی `elementor/` و مخزن `noratolanding/` مرجع استخراج نیستند. در ساخت این نسخه هیچ تغییری در فایل‌های مبنای `site/` داده نشده است.

## جدول شواهد

| موضوع | منبع جاری | تفسیر این بسته |
|---|---|---|
| پالت اصلی | `site/index.html`، بلوک `:root` | آبی، زرد، متن و سطوح فعلی |
| نقش فونت و مقیاس متن | `site/typography.css` | استعداد برای heading و وزیرمتن برای متن/کنترل |
| فونت واقعی بارگذاری‌شده | `site/assets/fonts/fonts.css` و README همان پوشه | میزبانی محلی؛ استعداد core وزن ۸۰۰ و وزیرمتن variable |
| CTA فعلی | overrideهای پایانی `index.html` و صفحهٔ تماس | هر دو دکمهٔ آبی و زرد با زمینهٔ استفادهٔ متفاوت |
| فرم و خطا | `site/contact.html`، `.field` و `.service-*` | ظاهر فرم و رنگ خطای موجود؛ قرارداد سراسری جدید پیشنهادی است |
| کارت و سطح | overrideهای پایانی `index.html` و `.panel` تماس | انتخاب چند شعاع/سایهٔ نماینده؛ همهٔ مقادیر یکسان نیستند |
| انتخاب و پیشرفت | `site/adventure-quest.css/js` | شواهد بصری نمونهٔ ماجراجویی؛ نه فرآیند واقعی اپ |
| تصویر و عملکرد | HTML فعلی، responsive assets و `video-facade.js` | ثبت اجرای موجود؛ بدون ادعای نمرهٔ عملکرد |

`evidence/root-inventory.json` بلوک‌های `:root` را با شمارهٔ خط ثبت می‌کند. `tokens.json` برای هر مقدار استخراج‌شده، منبع به شکل `path|selector|property` دارد. نام‌گذاری توکن‌های معنایی و قراردادهای جدید حتی اگر مقدارشان از برند گرفته شده باشد، «پیشنهادی» علامت خورده‌اند.

## تقدم منابع

برای این استخراج: دستور فعلی کاربر ← فایل‌های اصلاح‌شدهٔ `site/` و cascade واقعی ← قواعد ثبت‌شدهٔ این نسخه. اسناد تاریخی منبع تغییر طراحی نیستند. پس از پذیرش و نسخه‌بندی دیزاین سیستم، مصرف‌کننده باید به نسخهٔ مشخص قرارداد ارجاع دهد؛ تغییر تصادفی لندینگ نباید خودکار قرارداد همهٔ اپ‌ها را عوض کند.

تفاوت‌های شناسایی‌شده:

- `docs/architecture.md` هنوز از لاله‌زار و وابستگی runtime به Google Fonts حرف می‌زند؛ در فایل‌های اجرایی فعلی فونت‌ها استعداد و وزیرمتن و میزبانی محلی‌اند. آن توضیح قدیمی به این بسته منتقل نشده است.
- `specs/002-norato-website/` به دیزاین سیستم بیرونی و برخی رنگ/معناهای متفاوت اشاره دارد. آن مخزن خارجی و baseline تاریخی مبنای این کار نیستند. این بسته ادعای جایگزینی یا همگام‌سازی آن مخزن را ندارد.
- در CSS داخل صفحات مقدارهای قدیمی و overrideهای بعدی وجود دارد. مقدار اولیهٔ `.path-card` یا `h1` به‌تنهایی کافی نیست؛ ظاهر نهایی و فایل typography باید لحاظ شوند. برای مثال ورودی تماس در ابتدا ۵۰ پیکسل و دکمهٔ ارسال آبی است، اما در اجرای نهایی ورودی ۵۴ پیکسل و دکمهٔ ارسال زرد شده است؛ این نسخه مقدارهای نهایی را ثبت می‌کند.
- حلقهٔ فوکوس فعلی در همهٔ کنترل‌ها یکسان نیست و خط ورودی موجود روشن است. پیشنهاد دو لایهٔ فوکوس و مرز تیره‌تر عمداً با برچسب پیشنهادی ثبت شده است.

## محدودیت‌ها

این بسته طراحی اپ‌های احراز هویت‌شده را ندیده، رفتار API را بررسی نکرده، آزمایش با کاربر انجام نداده و ممیزی جامع دسترس‌پذیری نیست. جدول، مودال، تراکم اپ، وضعیت‌های تکمیلی و قراردادهای AI توسعهٔ پیشنهادی‌اند. فایل نشان رسمی، کتابخانهٔ فیگما و کامپوننت production در این تحویل وجود ندارد. تصاویر مرجع و گزارش مرورگر برای بررسی همین نمونه هستند، نه تأیید کل مجموعهٔ محصولات.

منابع استاندارد تکمیلی برای قواعد پیشنهادی: [کنتراست W3C](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)، [اندازهٔ هدف W3C](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)، [الگوی مودال W3C](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/). این منابع جایگزین منبع بصری نوراتو نیستند.
