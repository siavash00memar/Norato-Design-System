# قواعد صفحات عمومی و سئو

این راهنما مکمل دیزاین سیستم است؛ قواعد سئو به صفحات عمومی قابل ایندکس مربوط‌اند و نباید بی‌تمایز روی صفحه‌های داخل حساب اعمال شوند. این نسخه برنامهٔ انتشار یا ممیزی سئوی دامنه نیست.

## اجرای مشاهده‌شده در لندینگ اصلاح‌شده

- HTML فارسی و RTL، عنوان و توضیح صفحه، viewport و ساختار معنایی.
- فونت‌های محلی با preload فایل‌های core و `font-display:swap`.
- نسخه‌های responsive تصویر با `srcset`/`sizes`، عرض و ارتفاع مشخص و استفادهٔ موردی از lazy loading.
- لینک پرش به محتوای اصلی و رعایت کاهش حرکت در بخش‌هایی از کد.
- ویدیو و نمایش‌های تعاملی برای توضیح محصول؛ این نمایش‌ها قرارداد اپ واقعی محسوب نمی‌شوند.

وجود این موارد به‌معنای کافی‌بودن همهٔ متادیتا، صحت مقصدها یا نمرهٔ عملکرد معین نیست.

## قرارداد پیشنهادی برای توسعهٔ وب عمومی

1. هر صفحه موضوع، title و توضیح متناسب داشته باشد؛ عنوان دیداری اصلی و سلسله‌مراتب heading با محتوا هماهنگ باشد.
2. لینک پیمایش `href` واقعی و متن مقصد روشن داشته باشد؛ button برای عملیات استفاده شود.
3. canonical، robots و sitemap متناسب با **دامنه و مسیر نهایی انتشار** تعیین شوند؛ URL ساختگی وارد خروجی نشود. صفحهٔ نمونهٔ دیزاین سیستم و محیط آزمایشی با سایت اصلی اشتباه نشوند.
4. دادهٔ ساختاریافته فقط برای محتوای واقعی و نوع مناسب تولید شود؛ FAQ، امتیاز یا قیمت ساختگی صرفاً برای SEO اضافه نشود.
5. تصویر اصلی بالای صفحه به‌صورت پیش‌فرض lazy نشود؛ منابع پایین صفحه با توجه به نیاز بارگذاری شوند. اندازه و نسبت تصویر جلوی پرش چیدمان را بگیرد.
6. فونت همراه مجوز و وزن صحیح بارگذاری شود؛ preload فقط برای فایل موردنیاز همان صفحه باشد. عملکرد روی دستگاه/اتصال نماینده اندازه‌گیری شود؛ بدون اندازه‌گیری ادعای بهبود قطعی داده نشود.
7. قیمت، سال داده، مقصد خرید و متن پیشنهاد مالک و تاریخ بازبینی داشته باشند. «قبولی تضمینی» یا ادعای تأییدنشده وارد محتوا نشود.
8. خطاها، تغییر مسیرها و صفحات حذف‌شده با وضعیت HTTP مناسب و مقصد واقعی مدیریت شوند.

صفحات دادهٔ شخصی باید با احراز هویت و مجوز سمت سرور محافظت شوند. `noindex` و `robots.txt` کنترل دسترسی نیستند. برای صفحات عمومی و خصوصی، تصمیم ایندکس و امنیت جداگانه ثبت شود.

## پذیرش

HTML و مسیر مقصد نهایی، فونت/تصویر، موبایل، کنسول و درخواست‌های شکست‌خورده، ساختار محتوایی و متادیتا بررسی شود. ثبت canonical یا ارسال sitemap در این بسته انجام نشده است. راهنمای رسمی برای تکمیل تصمیم‌های انتشار: [Google Search Essentials](https://developers.google.com/search/docs/essentials) و [SEO Starter Guide](https://developers.google.com/search/docs/fundamentals/seo-starter-guide).
