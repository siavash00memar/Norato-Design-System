# گزارش بررسی نسخهٔ ۰٫۱٫۰

تاریخ: ۲۶ اکتبر ۲۰۲۶. محیط: Windows، Chrome headless، Playwright، فونت‌های محلی. دامنهٔ بررسی، همین بسته و نمونهٔ بصری آن است؛ اپ‌های واقعی نوراتو بررسی نشده‌اند.

## آنچه بررسی شد

- **تمامیت بسته:** همگامی JSON/CSS و سند یکپارچه، ارجاع توکن‌ها، لینک‌ها و فایل‌های محلی، وجود شواهد مقدارهای استخراج‌شده و عدم تغییر ۱۶ فایل مرجع فعلی. نتیجهٔ دقیق و تعداد بررسی‌ها در [verification.json](verification.json).
- **رنگ:** ۹ جفت‌رنگ مورد استفاده در قرارداد پیشنهادی، حداقل تعیین‌شدهٔ متن/مرز را می‌گذرانند. سه ترکیب نامناسب موجود یا محتمل نیز عمداً به‌عنوان مورد ممنوع/قابل اصلاح ثبت شده‌اند؛ fail آن‌ها نقص تولید بسته نیست. جزئیات در [contrast.json](contrast.json).
- **مرورگر:** ۱۷ بررسی شامل فونت واقعی لندینگ و مرجع، override نهایی فرم تماس، نبود overflow صفحه در پنج عرض، خطای فرم و فوکوس، بارگذاری و منع ارسال تکراری، جست‌وجو/بدون نتیجه/پاک‌کردن، radio با صفحه‌کلید، skip link، فوکوس دو لایه، کاهش حرکت، ورودی بلند و بزرگ‌نمایی متن. [browser-verification.json](browser-verification.json).
- **بازبینی بصری:** تصویر لندینگ فعلی و مرجع در دسکتاپ/موبایل مشاهده شد؛ ترتیب، فاصله، فونت، کارت، فرم و جدول برای همین نمونه بررسی شد.

## حدود بررسی

تست با screen reader، ممیزی کامل WCAG، کاربرپژوهی، بررسی چندمرورگری/دستگاه واقعی و اتصال به API انجام نشده است. بزرگ‌نمایی متن با CSS به‌عنوان proxy اجرا شد و معادل بررسی کامل زوم واقعی مرورگر نیست. پوشش عرض ۳۲۰ نیز جایگزین همهٔ سناریوهای reflow نیست. کتابخانهٔ production مودال، تب و جدول ساخته نشده؛ قراردادشان برای اجرا در اپ مستند است.

## بازتولید

از ریشهٔ بسته، `python tools/build.py` و `python tools/verify.py` را اجرا کنید. در نسخهٔ مستقل، اگر لندینگ کنار بسته نباشد، نتیجهٔ `baselineAvailable` برابر false است و تطبیق hash/شاهد منبع محلی اجرا نمی‌شود؛ فایل baseline همچنان برای تطبیق مستقل موجود است. بررسی فونت‌های کپی‌شده حتی در بستهٔ مستقل انجام می‌شود.

برای بازتولید بررسی مرورگر، پروژه‌ای شامل `site/` و `design-system/` را روی localhost سرو کنید و Playwright/Chrome نصب‌شده در محیط خود را معرفی کنید:

```text
node tools/browser-check.cjs <playwright-module-path> <chrome-executable> http://127.0.0.1:8791
```

برای مشاهدهٔ مستقل مرجع فقط به مرورگر نیاز است؛ نصب Playwright الزامی نیست. ابزار مرورگر به منابع محلی پروژه نیاز دارد و در ZIP مستقل بدون کنارگذاشتن لندینگ اجرا نمی‌شود. اسکریپت‌های یک‌بارمصرف استخراج baseline و ایجاد اولیهٔ توکن عمداً در بستهٔ توزیع نیستند تا شواهد مبنا تصادفی بازنویسی نشوند.
