# دیزاین سیستم نوراتو

**نسخهٔ ۰٫۱٫۰ — پیش‌نویس قابل بررسی | ۲۶ اکتبر ۲۰۲۶**

مرجع طراحی و توسعهٔ اپ‌های نوراتو، بر اساس **نسخهٔ اصلاح‌شدهٔ فعلی لندینگ** در `../site/`. این بسته از فایل ZIP اولیه، نسخه‌های پشتیبان `audits/`، خروجی المنتور یا طرح‌های تاریخی استخراج نشده است. فایل‌های فعلی لندینگ در ساخت این بسته تغییر نکرده‌اند.

## شروع استفاده

برای خواندن یا تحویل به‌صورت یک سند، [نسخهٔ یکپارچهٔ مستند](NORATO-DESIGN-SYSTEM.md) را باز کنید. فایل‌های موضوعی زیر منابع ویرایش همان سند هستند.

1. [مرجع بصری](reference/index.html) را در مرورگر باز کنید؛ فونت‌ها محلی و همراه بسته‌اند.
2. [قواعد پایه](foundations.md) و [قرارداد کامپوننت‌ها](components.md) را بخوانید.
3. برای بازطراحی از [راهنمای تحویل و پذیرش](delivery.md) و برای فیچر جدید از [قالب شرح فیچر](templates/feature-brief.md) استفاده کنید.
4. برای تحویل به AI، [راهنمای عامل](AGENTS.md) و مستندات مرتبط را کنار کد محصول قرار دهید؛ صرف ارسال تصویر کافی نیست.

## وضعیت قواعد

«استخراج‌شده» یعنی مقدار یا الگو در کد فعلی دیده شده؛ به معنای تصویب سراسری برای همهٔ محصولات نیست. «پیشنهادی» یعنی برای تکمیل نیاز اپ‌ها تدوین شده و در لندینگ قرارداد سراسری نداشته است. **کل بسته هنوز پیش‌نویس است**؛ انتشار ۱٫۰ پس از بررسی مالک محصول/طراحی و اجرای یک صفحهٔ واقعی صورت می‌گیرد.

| وضعیت | نمونه | کاربرد |
|---|---|---|
| استخراج‌شده | آبی `#356ae6`، زرد `#fdc101`، استعداد ۸۰۰، متن وزیرمتن | پایهٔ وفاداری به نسخهٔ اصلاح‌شده |
| پیشنهادی | فاصله‌های ۴ پیکسلی، معنای یکسان دکمه‌ها، جدول و مودال | قرارداد اولیه برای پیاده‌سازی آزمایشی |
| خارج از دامنه | معماری اپ‌ها، API، لوگوی رسمی، تم تیره | نیازمند منبع و تصمیم مستقل |

## استفاده در اپ

```css
/* @font-faceهای محلی را متناسب با مسیر محصول تعریف کنید. */
@import "./norato-design-system/tokens.css";

.product-action {
  min-height: var(--norato-size-control);
  padding-inline: var(--norato-space-6);
  border-radius: var(--norato-radius-control);
  background: var(--norato-color-action-default);
  color: var(--norato-color-action-text);
  font-family: var(--norato-font-family-ui);
}
```

توکن‌ها به React، Vue، Tailwind یا کتابخانهٔ خاصی وابسته نیستند. مرجع بصری نمونهٔ HTML/CSS/JS است و **کتابخانهٔ production کامپوننت‌ها نیست**. در هر اپ، توکن‌ها را به اجزای موجود نگاشت کنید و قرارداد رفتاری را حفظ کنید. فایل فیگما و پکیج React/Vue در این نسخه ساخته نشده‌اند.

## تولید و بررسی

با Python 3 و بدون نصب پکیج، از ریشهٔ همین پوشه:

```text
python tools/build.py
python tools/verify.py
```

`build.py`، CSS و گزارش کنتراست را از JSON و سند یکپارچه را از فایل‌های موضوعی تولید می‌کند؛ هیچ فایل لندینگ را تغییر نمی‌دهد. `verify.py` همگامی CSS، ارجاع توکن‌ها، لینک‌های داخلی و در صورت وجود `../site/`، تغییرنکردن منابع مبنا را کنترل می‌کند. برای مرور می‌توان `python -m http.server 8791 --bind 127.0.0.1` را اجرا و مسیر `/reference/` را باز کرد. روش بازتولید بررسی مرورگر و حدود آن در [گزارش بررسی](evidence/README.md) آمده است.

## تصمیم‌های باز

- تعیین مالک نگهداری و تصویب نسخه‌ها.
- انتخاب یک صفحهٔ پرتکرار از یک اپ برای پایلوت؛ کد اپ‌ها در این مخزن موجود نیست.
- نگاشت این قراردادها به فناوری و کامپوننت‌های واقعی هر اپ.
- بررسی لوگوی رسمی و مجوز تصویرسازی‌ها قبل از توزیع عمومی.
- تعیین تقویم، ارز، تم تیره و تراکم ویژهٔ پنل مشاوران بر اساس نیاز واقعی.
